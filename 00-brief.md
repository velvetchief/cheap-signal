# Cheap Signal

MTS Drops–style interactive editorial. One continuous scroll. One lab.

## Thesis

Cheap signals fail when **cost collapses** — reciprocal, zero-stakes, unlimited. Cosign only works if cosigns stay **costly**: reputation skin in the game, not LinkedIn-endorsement theater. Scarcity is expensive commitment (hire, check, IRL invite), not “Cosign invented belief.”

## What the reader should feel

The difference between a zero-cost attestation and a costly commitment — then a clear product intuition: Cosign survives only if the act stays expensive. Ease of reputation, intros, and access is fine. Collapse of cost is fatal.

## Sections

1. **Hook** — Cost collapse.
2. **Mechanism** — Cheap attestation vs costly commitment; scarcity by belief cost.
3. **Proof** — Photographers as canary (vanity and format shift / Reels / ads); residue venues as a snapshot, not a stable end state.
4. **Lab** — One slider on signal cost; seeded market model; outcomes that move when you settle.
5. **LinkedIn** — Why skill endorsements went to zero; what would keep a Cosign costly.
6. **Punchline** — Cheap cosigns (tweet/repost) vs expensive ones (hire, check, seed, IRL invite).
7. **Sources** — Cited reporting; explicit non-claims.

## Interaction

- Single continuous scroll. No dashboard chrome.
- Primary control: what one signal costs the sender (0 = free; 1 = costs you something), plus regime presets.
- Outcomes and scatter update on settle. Seeded model — not live telemetry.
- No sign-in, no forms, no CTA spam. Calm adult craft. Complete sentences.

## Ship checks

Rewrite before shipping if any of these fail:

1. Does it read like a product landing page? Cut CTAs and product screenshots; keep the mechanism.
2. Is the lab a black box? If outcomes cannot be explained from the model note → fix visibility.
3. Would a working photographer recognize themselves? If it feels like Tech Twitter cosplay → re-anchor in cited craft reporting.
4. Does LinkedIn endorsement kill the thesis unanswered? Address it head-on.
5. Does dragging cost prove a difference? If outcomes barely move → fix the model before shipping.
6. Did we invent a number? If a figure lacks a cite or “estimate” label → remove it.
